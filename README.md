# V-MediaWorks
1. `npm install`  2. `npm run dev`  3. `npm run build`
Formulari: kopjo `.env.example` në `.env` dhe vendos `VITE_FORM_ENDPOINT` (Formspree, Getform ose backend yti që pranon JSON POST).
Kontaktet dhe lidhjet sociale ndryshohen te `src/data.js` (CONTACT).
Projektet në portofolio janë demonstrative.
